Assuming 24 hours a day, shade = (24-sunlight), thus:

1.The estimate of shade coefficient is −8.97 which is the same size as the sunlight coefficient but with the opposite sign. Replacing sunlight with 24 − shade turns the term 8.97 × sunlight into 8.97 × (24 − shade). One extra shade hour means one less sunlight hour, which lowers expected height by 8.97 cm.

2. Only the intercept estimate changes. It becomes −10.36 + 24 × 8.97 = 204.90, because it now describes a plant with 0 shade hours (24 sunlight hours) instead of 0 sunlight hours.

3. The colour, greenhouse, plant type, soil type and soil pH coefficients stay the same, as do the fitted values and residuals. Shade is only a rearranged sunlight, so the model predicts exactly the same heights.

Including both. This is not a good idea. Shade plus sunlight always equals 24, so each variable can be calculated from the other and the intercept. This perfect multicollinearity means R cannot estimate both coefficients but reporting n/a.
