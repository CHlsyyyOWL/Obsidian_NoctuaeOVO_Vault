# 定位

第一章的反派组织，名字待定。

表面是一个第三方的藏品交易机构，非常资本主义。有钱就能在这里买到一切，想要的消息、想要的武器、想雇的保镖都能买到。

形象不正面。异能管理局内部知道或者察觉到，这是一个非常难处理的反派组织。

# 业务

- 拥有相对独家的武器制作技巧，因为技术太独家，业务铺得很广
- 拍卖会与武器交易
- 情报生意。买不起武器的人可以用情报抵押
- 雇佣，可以在这里雇到想要的保镖
- 付不起钱的可以用情报交易，付不起情报的可以用时间、寿命交易。收来的东西都可以被做成武器，或者被他们利用
- 情绪不能被付出，寿命可以

装备举例
- 针对特定灾难的东西，比如对应某种丧尸的特制血清和解药、对付鬼的符咒和特制桃木剑、对付吸血鬼的银器
- 给异能者的装备，比如身体强化型用的合金外骨骼、动力靴，精神操控型用来减少精神力消耗的特制项链

# 与共济会的对照

共济会比较社会主义，大家匿名，定期参加地下集会，以物易物，比较原始。穷人和没有实力的人才会去共济会。

有钱人和能力很强的人，会被这个机构招揽。

# 邪恶之处

搅浑水，下一盘大棋。一会儿跟这一方作对，一会儿跟那一方作对，所以管理局一开始也不知道他们站在哪一边。

# 理想

主人认为灾难是人类进化的阶梯。

如果这场灾难是洪水，那么他就要铸造诺亚方舟，就看你愿意押上什么作为船票。

# 人物

**主人**
- 男
- 把 A 养大，和 A 之间是非常纯粹、非常好的亲情

**A（少主）**
- 主人的孩子，明面上是机构的少主，出现在任何地方都前呼后拥
- 真心忠于主人和主人的理想
- 小时候和 B 是朋友，七八岁刚读完小学时，因为一个副本里一方为另一方牺牲而分开。B 后来成为异能管理局的新希望
- 外表冷静，内心没有放下和 B 的友情
